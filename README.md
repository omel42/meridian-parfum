Обновление 21 ноября 2026: глубокая зелёная палитра, новый первый экран «Аромат — личное.», восстановленное по фотографии вывески написание «МЕРИДИАН» и значок с его первой буквой. Поиск по русским названиям, быстрые подборки, цена за миллилитр, сравнение до трёх ароматов, недавние просмотры и подбор с объяснением.

Цены, ассортимент и доставка демонстрационные. Реальные заказы не создаются, деньги не списываются. Учётная система и платежи не подключены. Серверная WordPress/WooCommerce-версия подготовлена отдельно; здесь опубликована только статическая витрина.

Корзина, избранное, сравнение, история просмотров и ответы на вопросы хранятся только в браузере. Контакты из пробного оформления не сохраняются и не отправляются. Ответы владельца можно скачать текстом или JSON и передать самостоятельно; в репозитории ответов нет.

Исходные фотографии и данные ароматов: [SOURCES.md](SOURCES.md). Баннер сгенерирован; логотип и значок восстановлены с помощью генерации по реальной вывеске. Перед коммерческим запуском владелец подтверждает каталог, цены, наличие, условия продажи и права на использование материалов.
