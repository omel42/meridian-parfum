# Меридиан — версия 2

Публичный интерактивный макет магазина парфюмерии.

- [Магазин](https://omel42.github.io/meridian-parfum/)
- [24 вопроса владельцу](https://omel42.github.io/meridian-parfum/owner.html)
- [Разбор конкурентов и план запуска](https://omel42.github.io/meridian-parfum/research.html)

Обновление 21 ноября 2026: поиск по русским названиям и простым опечаткам, быстрые подборки, цена за миллилитр, сравнение до трёх ароматов, недавние просмотры, подбор с объяснением и мобильный интерфейс.

Цены, ассортимент и доставка демонстрационные. Реальные заказы не создаются, деньги не списываются. Учётная система и платежи не подключены. Серверная WordPress/WooCommerce-версия подготовлена отдельно; здесь опубликована только статическая витрина.

Корзина, избранное, сравнение, история просмотров и ответы на вопросы хранятся только в браузере. Контакты из пробного оформления не сохраняются и не отправляются. Ответы владельца можно скачать текстом или JSON и передать самостоятельно; в репозитории ответов нет.

Исходные фотографии и данные ароматов: [SOURCES.md](SOURCES.md). Логотип и баннер сгенерированы для макета. Перед коммерческим запуском владелец подтверждает каталог, цены, наличие, условия продажи и права на использование материалов.
