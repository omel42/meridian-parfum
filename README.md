# Меридиан — демонстрационный магазин парфюмерии

[Открыть сайт](https://omel42.github.io/meridian-parfum/)

Каталог из восьми ароматов, поиск, фильтры, избранное, подбор по предпочтениям, корзина и демонстрационное оформление заказа.

Цены иллюстративные. Оплата не подключена; контактные данные формы не отправляются. Корзина и избранное сохраняются только в браузере.

Фотографии товаров: источники в `SOURCES.md` и `products.json`. Иконка и редакционный баннер созданы с помощью генерации изображений. Шрифт Manrope распространяется по SIL Open Font License; лицензия включена в assets.
